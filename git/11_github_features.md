# 🧰 GitHub 협업/관리 기능 정리

## Issue
- 프로젝트의 할 일/버그/질문 관리 목적
- Label, 상태 관리가 협업을 굴림

## Labels
- 라벨 직접 만들고 색을 정해서 분류(예: `enhancement`)

## Milestone
- “어느 주기(스프린트)에서 해결해야 하는가”를 표시

## Projects (Kanban)
- GitHub에서 칸반 보드로 이슈/PR 관리
- 보통 관리자가 운영하는 게 효율적

## Wiki
- 내부 문서 공유(개인/팀 지식 정리)

## Organization
- 단체(팀) 단위 관리 공간
- People 탭에서 멤버/권한 관리
