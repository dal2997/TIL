# 🧠 Git이 뭐고, 왜 쓰는가

## ✅ Git 한 줄 정의
Git은 **버전 관리 + 협업** 도구다.  
단순 백업이 아니라 변경을 **이력(history)** 으로 남겨서 “언제/누가/왜”를 추적한다.

---

## 🔥 Git을 쓰는 이유 (내 기준)
- “아까 되던 코드”로 되돌릴 수 있음
- 팀원이 뭘 바꿨는지 비교 가능(diff)
- 브랜치로 기능을 안전하게 실험 가능(main 보호)

---

## 🌍 중앙집중형 vs 분산형
- 중앙집중형: 서버가 중심(서버 없으면 작업 어려움)
- 분산형(Git): 내 PC에 **전체 이력**이 있음 → 오프라인에서도 커밋 가능

---

## 🧩 머릿속 모델(이거만 고정)
Working → Staging → Commit → Remote

- Working: 내가 지금 수정 중
- Staging: “이번 커밋에 넣을 것만” 고르는 곳
- Commit: 스냅샷 저장(로컬)
- Remote: GitHub 같은 서버에 공유

---

## 💡 스냅샷 관점
Git은 “줄 수정”만 저장하는 게 아니라  
**커밋 시점의 프로젝트 상태(스냅샷)** 를 저장한다.
