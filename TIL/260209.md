# 2026-02-09 TIL

## ✅ Today
- **momonga-fanpage 다크/라이트 모드 오류 원인 해결**
  - 증상:
    - tailwind.config.ts 에서 `darkMode: "class"` 는 이미 설정되어 있었음
    - 다크모드 토글을 눌러도 특정 화면이 계속 **라이트 모드로 고정**
    - 특히 로그인 이후 / 일부 컴포넌트에서 배경이 계속 흰색으로 남음

- **핵심 원인 파악**
  - 문제는 Tailwind 설정이 아니라 **CSS 우선순위 + 전역 스타일 위치**
  - `src/app/globals.css` 내에
    - `html`, `body` 레벨에서 **라이트 컬러가 강제로 적용**
    - 다크모드 클래스보다 먼저/강하게 먹고 있었음
  - 즉,
    - 다크모드 토글 ❌
    - ThemeProvider ❌
    - Tailwind 설정 ❌  
    → **전역 CSS가 다 씹어먹고 있었던 상황**

- **해결**
  - `globals.css` **맨 위**에 다크/라이트 기준 스타일을 명시적으로 배치
  - 다크모드 기준이 되는 스타일이
    - 나중에 덮이는 게 아니라
    - **가장 먼저 선언되도록 순서 조정**
  - 그 결과:
    - 다크모드 정상 적용
    - 카톡 다크모드처럼 “부분만 하얀 화면” 문제 해결

- **중요한 깨달음**
  - `darkMode: "class"` 는 **조건**일 뿐
  - 실제로는:
    - 전역 CSS
    - reset 스타일
    - html/body 배경
    - 컴포넌트 단의 `bg-white`
  - 이 네 가지가 **항상 먼저 의심 대상**
