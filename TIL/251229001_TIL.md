1) CLI / Shell 기본 개념

CLI(Command Line Interface): 키보드로 명령을 입력해 OS에 작업 지시

Shell(Bash): 커널(운영체제 핵심)에 명령을 전달하는 인터페이스

파일탐색기 vs Bash: 둘 다 “파일/폴더 조작”을 하지만, Bash는 명령으로 직접 다룸

Multi-user OS: 사용자 계정별로 환경/권한/설정이 분리됨

2) 기본 명령어 (폴더 이동/확인)

pwd : 현재 작업 중인 폴더 출력 (예: /c/Users/user)

cd : 폴더 이동

어디 있든 cd만 치면 보통 유저 홈으로 이동

ls : 현재 폴더의 파일/폴더 목록

-a 숨김파일 포함(점 .으로 시작하는 파일)

-l 상세정보(권한/소유자/용량/날짜 등)

-al 숨김 + 상세

3) 파일/폴더 생성/이동/복사/삭제

mkdir dev : 폴더 생성

touch main.py : 파일 생성(텍스트류에 적합)

docx/ipynb/xlsx 같은 건 이렇게 만들면 정상 동작 보장 X

mv index.html bin : 파일 이동 / 이름 변경에도 사용 가능

mv README_copy.md readme.txt = rename

cp README.md ./README_copy.md : 복사(같은 위치면 새 이름 지정 필요)

와일드카드(패턴 매칭)

* = “모든 것”

mv server.* bin : server로 시작하는 모든 확장자 파일 이동

mv __*.py bin, mv *e.* bin, mv *ai*.* bin

삭제 개념(느낌 차이)

remove: “접근/참조를 제거”

delete: “실제 데이터를 지움”
(한글 번역에서는 잘 구분 안 하지만, 개념을 알고 있으면 좋음)

삭제 명령

rm README.md : 파일 삭제

rmdir bin : 빈 폴더만 삭제(안 비면 실패)

rm -r bin : 폴더 안 내용까지 전부 삭제하고 폴더도 삭제

4) Vim 기초 (CLI 텍스트 편집기)

Vim: 무료/오픈소스, CLI 환경에서 강력(서버/클라우드/키오스크 입력 등에 유용)

파생: neovim, macvim 등

플러그인(예: vim-plug) 없으면 단순 편집기, 있으면 생산성 ↑

모드 개념

Normal: 기본 모드(대부분 여기서 시작)

Insert: 입력 모드 (i)

Visual: 선택 모드 (v)

Command-line: 명령 모드 (:)

자주 쓰는 커맨드

종료: :q

저장: :w

저장 후 종료: :wq (가장 많이 사용)

줄번호: :set nu

공백 표시: :set list / 끄기 :set nolist

특정 줄 이동: :10

모드 탈출: Esc

6) Git / 협업 구조 개념

중앙집중형 vs 분산형 버전관리

중앙집중형: 서버 중심, 협업 상황을 항상 공유/동기화하는 느낌

Git(분산형): 로컬에서 독립적으로 작업 가능, 브랜치/실험(평행우주) 가능

Git 내부 객체 개념

blob: 파일 내용(변경사항)

tree: 디렉토리 구조/메타데이터(이름, 경로 등)

commit: 특정 시점의 스냅샷(상태 기록)

작업 흐름

Working directory → Staging area → Local repo → Remote repo

git add : 변경사항을 스테이징(변화량 올리기)

git commit : 스냅샷 생성(메타데이터 포함)

git push : 원격 저장소로 업로드

7) GitHub / GitLab / Bitbucket 차이

Git: 버전관리 “도구”

GitHub/GitLab/Bitbucket: Git 저장소를 올려서 협업하는 “서비스”

GitLab: 사내망(온프레미스) 구축 가능 → 보안에 강함(금융권 등)

14) Bash 히스토리 기록/저장
히스토리 자동 누적 설정(~/.bashrc)
export HISTFILE=~/.bash_history
export HISTSIZE=100000
export HISTFILESIZE=200000
shopt -s histappend
export PROMPT_COMMAND='history -a'


적용: source ~/.bashrc

저장 예시

전체 저장: history > history.txt

날짜 파일명 저장:

history > "history_$(date +%Y-%m-%d).txt"

최근 200개만:

history 200 > "history_$(date +%Y-%m-%d)_last200.txt"

시간까지 기록:

echo 'export HISTTIMEFORMAT="%F %T "' >> ~/.bashrc

source ~/.bashrc

오늘 날짜만 필터:

history | grep "^$(date +%F)" > "history_$(date +%F)_today.txt"

출력까지 로그로 남기기:

git status 2>&1 | tee -a "session_$(date +%F).log"
