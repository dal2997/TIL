# 📅 2026-01-29 TIL

## ✅ Today (배운 것)
- **Sigil(ePub 편집기) 구조 이해**
  - ePub = **HTML + CSS + 메타데이터(OPF) + 목차**
  - Sigil은 “특수한 툴”이 아니라  
    **웹 문서를 책 포맷으로 관리하는 도구**라는 점 명확히 이해
  - 처음 마주할 때 무서운 UI의 정체를 정확히 파악함

- **Sigil 기본 작업 흐름 정리**
  - ePub 열기 → 본문(xhtml) 확인 → CSS 하나로 스타일 통제
  - 디자인보다 중요한 건:
    - 문서 구조
    - 파일 정합성
    - 목차/흐름의 안정성

- **무료 ePub 리소스 & 포맷 판단 기준 학습**
  - PDF ≠ 편집용
  - HTML 가능하지만 번거로움
  - **ePub 원본 + DRM 없음**이 최적이라는 결론

- **툴 공포 극복**
  - “처음 보는 툴 = 새로운 기술”이 아니라
  - 이미 아는 개념을 **다른 UI로 다시 만나는 것**이라는 인식 전환
