### 2) ChatGPT가 뭘 열어보는 것과 내 PC 감염은 별개

- 그래서 원칙은:
  - 출처 불명 파일은 실행 금지
  - 코드는 내용 이해 후 실행
  - 필요하면 샌드박스/가상환경/격리된 폴더에서 테스트

### 3) `pd.get_dummies()` (One-Hot Encoding) 왜 하냐?
- 모델은 문자열을 계산 못 하니까 **범주형 데이터를 숫자 벡터로 바꿔야** 함.
- 더미 변수는 “이 범주냐/아니냐(0/1)”로 바꿔서 학습 재료로 만든다.

~~~python
import pandas as pd

df = pd.DataFrame({"dept": ["Sales", "IT", "Sales"]})
pd.get_dummies(df, columns=["dept"])
~~~

---

### 4) `value_counts()` vs `nunique()` 차이
- `value_counts()` : 각 값이 **몇 번** 나왔는지 “분포표”
- `nunique()` : 서로 다른 값이 **몇 개** 있는지 “가짓수”

~~~python
s = df["dept"]

s.value_counts()  # Sales:2, IT:1
s.nunique()       # 2
~~~

> `value_counts()` 결과를 보면 “유니크한 값들이 나열”돼서 `nunique()`처럼 느껴질 수 있는데,  
> 핵심 차이는 **counts(빈도)**를 주냐 vs **개수(유니크 수)**만 주냐.

---

### 5) `lr.coef_` 와 `coef` 뜻
- `coef` = **coefficient(계수)**의 줄임말
- 선형회귀에서 `lr.coef_`는  
  **각 피처(특성)가 예측값에 미치는 영향(가중치)** 을 의미.

~~~python
# y = w1*x1 + w2*x2 + ... + b
# lr.coef_  => [w1, w2, ...]
# lr.intercept_ => b
~~~
