### ☀️ 오후: RandomForest로 취소 예측 흐름 학습 + 평가 지표/튜닝
- 범주형 처리 필요성 재확인
  - object 컬럼 → 원-핫 인코딩(`pd.get_dummies`)로 숫자화
  - `country`처럼 카테고리 수가 과도한 변수(고카디널리티)는 성능/비용 관점에서 drop 고려
- Train/Test 분할 & 모델 학습 흐름 잡기
  - `train_test_split(..., random_state=100)`로 재현성 확보
- 평가 지표 체감
  - `accuracy_score`, `confusion_matrix`, `classification_report`로 “1(취소)”에 집중해서 보기
  - `roc_auc_score`는 **예측 클래스(0/1)가 아니라 확률(predict_proba)** 로 계산해야 의미 있음
- 하이퍼파라미터 튜닝 감 잡기
  - `max_depth`, `min_samples_split` 바꿔가며 AUC 변화를 확인
  - “각 파라미터별 베스트를 그냥 합친 조합이 항상 최적은 아니다”를 직접 체감
- `GridSearchCV`의 `cv` 의미 정리
  - `cv=5`는 (이번 케이스에선) **X_train을 5등분해서 교차검증**으로 평균 성능을 보는 것
  - 그래서 “그냥 단일 hold-out 성능”과 숫자가 다르게 나올 수 있음

## 🧠 오늘 배운 핵심
- 범주형(object)은 모델이 못 먹으니 → 원-핫 인코딩으로 숫자화가 기본
- ROC-AUC는 “확률 예측” 기반 지표 → `predict_proba`가 핵심
- 하이퍼파라미터는 **각각 최적 ≠ 조합 최적**
- `GridSearchCV(cv=k)`는 “훈련셋 내부를 k-fold로 쪼개 평균 성능”을 본다 (hold-out이랑 결과가 달라져도 정상)
