# 02_loss_bias_variance.md
> Regression Problem — Loss / Bias / Variance

---

## 0️⃣ 이 파일의 목표

> **왜 모델이 “너무 단순해도 문제”이고  
> “너무 복잡해도 문제”인지  
> 한 장의 그림처럼 떠올릴 수 있게 만든다.**

이 파일을 이해하면:
- “과적합이 왜 생겼는지”
- “왜 Regularization이 필요한지”
를 **말로 설명할 수 있게 된다.**

---

## 1️⃣ 다시 시작: 우리가 최소화하려는 것

이전 파일에서 정리한 핵심:

> **회귀의 목표 = 전체 Loss 최소화**

$$
\text{Total Loss}
= \sum_{i=1}^{N} (y_i - \hat{y}_i)^2
$$

하지만 중요한 사실 하나:

> ❗ 이 Loss는 **모델 + 데이터 + 운**이 섞여서 나온 결과다.

---

## 2️⃣ Error를 세 조각으로 나누면 보이는 것

### 2-1. Error의 분해 (핵심 공식)

$$
\text{Error} = \text{Noise} + \text{Bias} + \text{Variance}
$$

이건 **공식 암기용이 아니라, 사고 프레임**이다.

---

## 3️⃣ 세 가지 요소를 직관적으로 이해하기

### 3-1. Noise (데이터의 한계)

> **아무리 잘해도 못 맞추는 영역**

- 측정 오차
- 사람 행동의 랜덤성
- 설명되지 않는 외부 요인

예:
- 같은 공부 시간 → 점수가 항상 같지 않음

👉 **Noise는 모델로 해결 불가**  
👉 데이터/도메인의 한계

---

### 3-2. Bias (편향) — 모델이 너무 단순할 때

> **모델의 평균 예측이 정답과 멀리 떨어져 있음**

- 가정이 너무 강함
- 표현력이 부족함

예:
- 실제 관계는 곡선인데, 직선만 허용
- 중요한 변수를 아예 안 넣음

특징 요약:

| 항목 | Bias |
|---|---|
| 모델 복잡도 | 낮음 |
| 학습 데이터 | 잘 못 맞춤 |
| 테스트 데이터 | 당연히 못 맞춤 |
| 상태 | **Underfitting** |

---

### 3-3. Variance (분산) — 모델이 너무 복잡할 때

> **데이터에 따라 예측이 심하게 흔들림**

- 훈련 데이터 하나하나에 과도하게 반응
- 노이즈까지 외움

예:
- 샘플 하나 추가했는데 예측이 확 바뀜
- 트리가 너무 깊음

특징 요약:

| 항목 | Variance |
|---|---|
| 모델 복잡도 | 높음 |
| 학습 데이터 | 매우 잘 맞춤 |
| 테스트 데이터 | 성능 급락 |
| 상태 | **Overfitting** |

---

## 4️⃣ Bias vs Variance 한 장 요약

~~~text
Bias ↑ / Variance ↓   |   Bias ↓ / Variance ↑
---------------------------------------------
단순 모델            |   복잡한 모델
Underfitting         |   Overfitting
~~~

> 중요한 건  
> **Bias를 줄이면 Variance가 늘고,  
> Variance를 줄이면 Bias가 늘 수 있다는 점**

이게 바로 **Trade-off**다.

---

## 5️⃣ 시각적으로 떠올리기 (과녁 비유)

| 상황 | 의미 |
|---|---|
| 과녁 중심에서 멀리 + 모여 있음 | Bias 큼 |
| 과녁 주변에 흩어짐 | Variance 큼 |
| 중심에 고르게 모임 | 이상적 |

👉 이 그림이 **머릿속에 바로 떠오르면 성공**

---

## 6️⃣ 모델 복잡도와 Error의 관계

### 6-1. 모델 복잡도 증가시키면?

| 요소 | 변화 |
|---|---|
| Bias | 감소 |
| Variance | 증가 |
| Training Error | 감소 |
| Test Error | 처음엔 감소 → 이후 증가 |

👉 Test Error가 최소가 되는 지점이 **우리가 원하는 모델**

---

## 7️⃣ 그래서 “Loss만 최소화하면 안 되는” 이유

> ❌ Training Loss만 최소화  
> ⭕ **Generalization Error** 최소화

즉,

- 훈련 데이터 잘 맞추는 모델 ❌
- **보지 못한 데이터도 잘 맞추는 모델** ⭕

---
