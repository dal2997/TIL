# 03. LIME (Local Interpretable Model-Agnostic Explanations)

이 파일은 **Local explanation의 출발점인 LIME**을 다룬다.  
핵심은 “LIME이 무엇을 잘하고, 무엇을 못하는가”이다.

---

## 1️⃣ LIME이 등장한 배경

앞선 파일에서 봤듯이,
- Global importance는 전체 평균
- 우리는 **특정 샘플 하나**를 설명하고 싶다

그래서 나온 질문:
> “이 예측 하나만이라도 설명할 수 없을까?”

👉 이 질문에 대한 첫 번째 실질적 해법이 **LIME**이다.

---

## 2️⃣ LIME 이름 그대로 풀기

LIME는 네 단어의 조합이다.

- **Local**
  - 특정 데이터 포인트 하나
- **Interpretable**
  - 사람이 이해 가능한 모델로 설명
- **Model-Agnostic**
  - 어떤 모델이든 사용 가능
- **Explanation**
  - 예측에 대한 설명 제공

---

## 3️⃣ LIME의 핵심 아이디어 (직관)

> “복잡한 모델을  
> 선택한 샘플 **주변에서만** 단순 모델로 흉내 내자”

즉,
- Global 모델은 그대로 둠
- **Local 영역에서만 선형 근사**

---

## 4️⃣ LIME 동작 과정 (Step-by-step)

### Step 1. Black Box 모델 학습
- 기존에 쓰던 모델 그대로 사용
- Regression / Tree / Boosting / DL 모두 가능

---

### Step 2. 설명할 샘플 선택
- 우리가 궁금한 **특정 데이터 1개**
- 예: 고위험으로 분류된 고객

---

### Step 3. Perturbation (교란 데이터 생성)

선택한 샘플 주변에서:
- 변수 값을 조금씩 바꿔
- **여러 개의 가짜 샘플** 생성

~~~text
원본 샘플 x
→ x₁', x₂', x₃', ...
(주변 점들)
~~~

---

### Step 4. Black Box 모델로 예측
- 생성한 모든 샘플에 대해
- 기존 모델로 예측값 계산

---

### Step 5. Local surrogate model 학습
- 입력: 교란된 샘플
- 출력: Black Box 예측값
- 모델: **선형 회귀 / Lasso 등 단순 모델**
- 거리 가중치 적용:
  - 원본 샘플에 가까울수록 가중치 ↑

---

### Step 6. 계수로 설명
- surrogate 모델의 계수
- → 해당 샘플에서의 변수 중요도

---

## 5️⃣ LIME의 장점

- 모델 종류에 관계없이 사용 가능
- 직관적
- 계산 비용 비교적 낮음
- 텍스트 / 이미지 / 수치 데이터 모두 가능

---

## 6️⃣ LIME의 치명적인 한계

### ❗ 1. 불안정성 (Instability)
- Perturbation 샘플링에 의존
- 실행할 때마다 결과가 달라질 수 있음

---

### ❗ 2. Local 정의가 애매함
- “어디까지가 주변인가?”
- σ, 샘플 수, 거리 함수에 따라 설명이 바뀜

---

### ❗ 3. Global 확장 불가
- 여러 샘플 설명을 평균낸다고
- Global explanation이 되지는 않음

---

[O### ❗ 4. 이론적 보장 부족
- 왜 이 계수가 “공정한 기여도”인지
- 명확한 수학적 근거 부족

---

## 7️⃣ LIME 요약 한 줄

> LIME은  
> **“Local explanation의 훌륭한 출발점이지만,  
> 신뢰하기에는 불안정하다.”**

그래서 등장한 것이 **SHAP**이다.
