# 🚀 다음으로 더 알아두면 좋은 Git 주제들

## 1) reset / revert 차이 완전정복
- 실수 커밋 되돌리기에서 가장 중요한 주제

## 2) rebase -i (인터랙티브 리베이스)
- 커밋 메시지 정리, squash, fixup

## 3) cherry-pick
- 필요한 커밋만 골라서 다른 브랜치로 가져오기

## 4) reflog
- “망했다” 싶을 때 살려주는 마지막 생명줄

## 5) stash 심화
- 여러 작업 임시 저장/복원 패턴

## 6) GitHub Actions 기초
- CI에서 테스트/린트 자동화

원하면 이 파일을 기반으로 `16_...`부터 확장해도 됨.
