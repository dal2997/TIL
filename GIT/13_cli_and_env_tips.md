# 🧩 CLI & 환경 팁 (내가 계속 삽질한 것들)

## clone 폴더명 바꿔서 받기
``` bash
git clone <URL> ./새폴더명
```

## rm -rf (진짜 위험)
- `rm`: 삭제
- `-r`: 폴더 내부까지 재귀 삭제
- `-f`: 강제(확인 없이 삭제)

안전하게는:
``` bash
rm -rI 폴더명
```

## 붙여넣기 팁 (Git Bash)
- 보통 `Shift + Insert`가 제일 안정적
- Tab 자동완성 적극 사용(파일명/브랜치명 오타 방지)

## 오타가 치명적인 것들(내가 실제로 당함)
- `FETCH_HEAD`
- 파일명 오타
- 브랜치명 오타
